# Урок 9

## ЗАДАНИЕ Find and Replace

Программа поиска и замены текста в файлах<br>
Необходимо создать полезную утилиту, которая будет искать и заменять указанную строку в текстовых файлах в директории.<br>
Это CLI программа, которая будет пошагово опрашивать пользователя.<br>

Пользователь должен будет задать:<br>

1. Путь к директории<br>
2. Строка поиска<br>
3. Строка замены<br>

После программа ищет все текстовые файлы (txt) в папке и заменяет все вхождения заданной строки в текстовых файлах в этой директории.
