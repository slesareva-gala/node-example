## ЗАДАНИЕ 1

### To-Do CLI

Напишите CLI-приложение для управления задачами (To-Do List).<br>
Приложение должно позволять пользователю создавать, просматривать, обновлять и удалять задачи.<br><br>

<b>Требования:<b/><br>
Приложение должно быть запускаемым из командной строки и принимать команды от пользователя.<br><br>

Приложение должно поддерживать следующие команды:<br>
<b>add < task ></b>: добавить новую задачу.<br>
<b>list</b>: вывести список всех задач.<br>
<b>get < id ></b>: вывести информацию о задаче с указанным идентификатором.<br>
<b>update < id > < newTask ></b>: обновить задачу с указанным идентификатором.<br>
<b>status < id > < newStatus ></b>: обновить статус задачи с указанным идентификатором.<br>
<b>delete < id ></b>: удалить задачу с указанным идентификатором.<br><br>

Задачи должны сохраняться в файле, чтобы они могли быть доступными между разными запусками приложения.<br>
Приложение должно использовать модульную структуру для разделения функциональности, например, модули для работы с задачами, обработки команд и взаимодействия с файловой системой.
