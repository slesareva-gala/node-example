# Урок 12

## ЗАДАНИЕ: Разработать CLI программу, которая имеет 2 основных функционала:

1. Создание хеш файла для исходного файла и сжатие этого файла<br>
   *1.1. Тип данных может быть любой (текст, изображение, аудио и т.д.)<br>
   *1.2. Хеш файл и архив создаются рядом с основным файлом<br><br>

2. Распаковка и проверка целостности файла<br>
   *2.1. Распаковывает файл gz и на основе его имени создает файл<br>
   *2.2. Проверяет хеш созданного файла с хешом который находится рядом с архивом<br>

### Требования:

1. Выберите произвольные данные для работы (например, текстовый файл, изображение, аудиофайл).<br>
2. Используйте модуль crypto для создания хеша (SHA-256).<br>
3. Сохраните хеш в файл<br>
   *a. например у вас файла text.txt<br>
   *b. создается файл text_txt.sha256<br>
4. Используйте модуль zlib для сжатия выбранных данных.<br>
5. Сохраните сжатые данные в новый файл<br>
   *a. например у вас файл test.txt<br>
   *b. создается файл text_txt.gz<br>
6. Реализуйте проверку целостности данных: сжатие и хеш можно прочитать из файлов, декомпрессировать сжатые данные с модулем zlib, затем сравнить хеш их файла .sha256 и хешом распоковываного файла<br>
7. Выведите информацию о соответствии хешей на экран.<br>
