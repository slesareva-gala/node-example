## ЗАДАНИЕ 2

Создайте программу, которая выводит сообщения.<br>
Пользователи смогут отправлять сообщения с помощью функции sendMessage, а функция receiveMessage будет получать и отображать эти сообщения.<br>
sendMessage принимает два параметра username и message<br>
<br>
<i><u>Подсказки:</u></i>
<i>Напишите функцию для отправки сообщений пользователями sendMessage.<br>
Когда пользователь отправляет сообщение, вызывайте соответствующее событие с информацией о сообщении.<br>
Напишите функцию receiveMessage для получения сообщений, она должна подписываться на событие, которое пользователь вызывает при отправке сообщения, и выводить информацию о сообщении в консоль.<br>
Инициализируйте функцию получения сообщений.<br>
Напишите несколько сообщения от пользователя, и удостоверьтесь, что сообщения успешно выводятся в консоль.</i>
