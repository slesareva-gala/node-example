## ЗАДАНИЕ 1

### Напишите программу для копирования папки

Функция принимает 3 параметра:<br>
sourceDir (строка) - путь к исходной директории, содержимое которой нужно скопировать.<br>
targetDir (строка) - путь к целевой директории, в которую нужно скопировать содержимое исходной директории.<br>
callback (функция) - функция обратного вызова, которая будет вызвана после завершения копирования. Коллбэк должен принимать один аргумент - ошибку (если есть), или null, если операция прошла успешно.<br><br>

<i><b>Важно:</b>
Необходимо использовать рекурсивные вызовы для обхода содержимого исходной директории.<br>
Если в исходной директории обнаружена поддиректория, создайте соответствующую поддиректорию в целевой директории.<br>
Если в исходной директории обнаружен файл, скопируйте его в целевую директорию <br>
Для проверки создайте директорию в которой будут пару папок внутри с разными типами и именами файлов<br>
Обязательно проверьте копирование для файлов размером 5 - 10 Мегабайт</i><br>

## ЗАДАНИЕ 2

### Напишите класс Logger для логирования

Создайте класс Logger, который будет расширять EventEmitter.<br>
constructor(filename, maxSize): Конструктор класса. Принимает два аргумента:<br>
filename (строка) - имя файла лога, в который будут записываться сообщения.<br>
maxSize (число) - максимальный размер файла лога в байтах.<br>
Логи записываются в начало и обрезаются с конца, когда файл превышает maxSize.<br>
В конструктор инициализируем поля объекта:<br>
имя файла(filename)<br>
максимальный размер(maxSize)<br>
очередь логов(logQueue - array)<br>
флаг записи(writing - boolean)<br><br>

<i><b>Определите методы:</b>

log(message): добавляет сообщение в начало logQueue и вызывает метод writeLog, если запись в файл в данный момент не выполняется, устанавливает флаг writing в значение true.<br>
writeLog(): Записывает файл лога из массива logQueue и очищает его. Генерирует событие 'messageLogged'. Вызывает метод проверки размера файла checkFileSize.<br>
Если в массиве logQueue есть еще сообщения лога, рекурсивно вызывает метод writeLog.<br>
Если в массиве logQueue больше нет сообщений лога, устанавливает флаг writing в значение false.<br>
getFileSize(): с помощью fs.stat получает информацию о размере файла и возвращает его размер в байтах. Если возникает ошибка при получении информации о файле, возвращает 0.<br>
checkFileSize(): Если текущий размер файла превышает максимальный размер, вызывает метод rotateLog для выполнения ротации лога.<br>
rotateLog(): Создает резервную копию файла с расширением .bak (копируя текущий лог-файл), затем обрезает текущий лог-файл с помощью метода fs.truncate<br>

<i><b>Проверка работы</b>

```js
const logger = new Logger('log.txt', 1024);

logger.on('messageLogged', message => {
  console.log('Записано сообщение:', message);
});

logger.log('Первое сообщение');

logger.log('Второе сообщение');
```
