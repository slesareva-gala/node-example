### Напишите функцию для обработки изображений resizeImage(inputPath, outputPath)

Функция будет принимать путь к изображению в формате JPEG и выполнять следующие операции:<br>
Загружать изображение с указанного пути.<br>
Изменять его размер (400px x 400px)<br>
Сохранять преобразованное изображение на диск.<br>

Для выполнения задачи установите плагин sharp(link), импортируйте его<br><br>

sharp использует stream поэтому вы можете использовать process<br><br>

Для изменения размера используйте метод resize: sharp().resize(400, 400).toFormat('jpeg')<br><br>

Для практики работы с sharp дополнительно создайте вторую функцию, которая будет преобразовывать изображение в оттенки серого и применять эффект размытия<br>
