## ЗАДАНИЕ 1: КВИЗ

### Напишите программу Квиз, с использованием readline и process

1. В уроке приложен файл с вопросами, его необходимо будет подгружать при запуске программы.<br>
2. Программа должна использовать консольный ввод и вывод для взаимодействия с пользователем. <br><br>
3. В начале программы, выведите приветственное сообщение и инструкции для пользователя.<br>
4. Создайте переменные для отслеживания текущего вопроса и количества правильных ответов. Изначально оба значения должны быть равны 0.<br>
5. На каждой итерации квиза, выведите текущий вопрос и варианты ответов.<br>
6. Пользователь должен будет ввести номер варианта ответа<br>
7. Проверьте, является ли введенный ответ числом и находится ли он в диапазоне допустимых значений.<br>
8. Если число валидно, то проводим проверку на правильность, если число невалидно, то задаем вопрос снова.<br>
9. Если введенный ответ правильный, увеличьте счетчик правильных ответов.<br>
10. После каждого ответа, выведите сообщение о том, правильный ли был выбран ответ.<br>
11. Перейдите к следующему вопросу и повторите шаги с 6 по 10 до тех пор, пока не пройдетесь по всем вопросам из массива.<br>
12. По окончании квиза, выведите сообщение о завершении и общее количество правильных ответов.<br>
